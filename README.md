# My-Linux: Modern Scrolling-Tiling Desktop Environment & Opinionated OS

Независимое, легковесное и бескомпромиссное десктопное окружение (DE) и дистрибутив на базе **Void Linux**, построенное по философии Unix и принципам максимальной производительности (Rust-only, Wayland-first, Scrolling-first).

---

## 🧭 Ключевые принципы

1. **Scrolling-first (ленточный тайлинг):** Основан на форке **Niri** с бесконечной горизонтальной лентой колонок — самый эргономичный способ организации окон для современных дисплеев и ультрабуков.
2. **Wayland & Rust First:** Все компоненты системы написаны на Rust с фокусом на минимальное потребление ОЗУ, мгновенный отклик и типобезопасность.
3. **Аппаратные фиксы и HDR "из коробки":**
   - Полная поддержка расширенного динамического диапазона (HDR) через протоколы `wp_color_management_v1` и `frog_color_management_v1` (готовность к современным 3.1K OLED панелям и HDR в играх через Proton/Wine).
   - Поддержка `linux-drm-syncobj-v1` (Explicit Sync) — устранение статтеров и задержек на GPU Intel, AMD и Nvidia.
   - Поддержка `wp_tearing_control_v1` (async pageflips) и прямой скан-аут (Direct Scanout) для сверхнизкого инпут-лага в играх.
   - Нативное сворачивание окон (Minimizing).
4. **Void Linux First:**
   - Никакой зависимости от `systemd`.
   - Собственный легковесный диспетчер сессий (`session/`), обеспечивающий D-Bus активацию порталов (`xdg-desktop-portal`), PipeWire и супервизию процессов окружения.
5. **Opinionated OS:**
   - Btrfs с сабволюмами и автоматическими снапшотами Snapper.
   - Полнодисковое шифрование LUKS2 + авторазблокировка через TPM2 PIN + Secure Boot.
   - Загрузчик Limine с поддержкой прямого старта из Btrfs-снапшотов.
   - Встроенный AI-ассистент с аппаратной базой знаний конкретного устройства.

## 📂 Структура репозитория

```
my-linux/
├── compositor/           # Патченный композитор Niri (HDR, Tearing, SyncObj, Minimizing, Vulkan)
├── smithay/              # Модифицированный Smithay (DRM atomic colorop, HDR connectors)
├── session/              # [В разработке] Rust Session Manager для Void Linux (замена systemd --user)
├── shell/                # [В разработке] Системный шелл (панель, трей, OSD, Quick Settings)
├── scripts/              # Скрипты запуска и тестовые конфигурации
│   ├── run-nested.sh     # Запуск композитора во вложенном окне на текущем десктопе
│   └── nested-config.kdl # Конфигурация для быстрого тестирования (Mod = Alt)
├── packages/             # [В разработке] Шаблоны сборки пакетов xbps-src
└── docs/                 # Документация и исследования
    ├── RESEARCH.md       # Сравнительный анализ форков Niri и решений проблем
    └── ARCHITECTURE.md   # Архитектурный план компонентов DE
```

## 🚀 Быстрый старт (Тестирование на хосте)

Для быстрого цикла разработки не требуется выходить из текущего сеанса или перезагружаться. Композитор запускается как обычное окно внутри текущего сеанса (Hyprland / CachyOS).

### Запуск во вложенном окне:
```bash
./scripts/run-nested.sh
```

Внутри окна клавиша `Mod` автоматически назначена на **`Alt`**, чтобы не перехватывать системные хоткеи хоста (`Super`):
- `Alt + Enter` / `Alt + T` — открыть терминал (`alacritty`)
- `Alt + D` — лаунчер приложений (`fuzzel`)
- `Alt + Q` — закрыть окно
- `Alt + M` — свернуть окно (Minimize)
- `Alt + H / L` (или `Alt + Left / Right`) — горизонтальный скроллинг колонок
- `Alt + Tab` / `Alt + O` — режим обзора (Overview)
- `Alt + Shift + E` — закрыть вложенный сеанс
